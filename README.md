# inklineapps.github.io

The public site for **Inkline Apps** — product pages, privacy policies and documentation for
our Atlassian Marketplace apps.

```
index.html                    Inkline Apps home, lists every app
style.css                     shared styling, light + dark
sharp-mermaid/index.html      Sharp Mermaid product page
sharp-mermaid/privacy.html    Sharp Mermaid privacy policy
sharp-mermaid/docs.html       Sharp Mermaid documentation
privacy.html, docs.html       redirects to their sharp-mermaid/ equivalents
```

Each app gets its own folder, so a second app is a new directory and one card on the home
page — nothing else moves.

Plain static HTML. No build step, no dependencies, no JavaScript, no tracking.

Support: support@inklineapps.com
